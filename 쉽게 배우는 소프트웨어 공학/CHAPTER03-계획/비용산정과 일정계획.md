

# 1. 일정계획 기법 정리 표

| 기법          | 개념                        | 시간 산정 방식       | 장점             | 단점               | 적합한 경우          |
| ----------- | ------------------------- | -------------- | -------------- | ---------------- | --------------- |
| Gantt Chart | 시간 축 기준으로 작업 일정을 막대로 표현한다 | 확정 시간          | 직관적이고 이해가 쉽다   | 작업 의존 관계 표현이 어렵다 | 소규모, 단순 프로젝트    |
| CPM         | 임계경로를 계산하여 전체 일정을 관리한다    | 확정 시간          | 일정 단축 분석이 가능하다 | 불확실성 반영이 어렵다     | 반복적·예측 가능한 프로젝트 |
| PERT        | 확률 기반으로 기대 시간을 계산한다       | 확률 시간(O, M, P) | 불확실성 관리에 강하다   | 계산이 복잡하다         | 연구·개발 중심 프로젝트   |

# 2. 비용산정기법 분류 표

| 분류    | 기법     | 개념                  | 특징        | 장점          | 단점            |
| ----- | ------ | ------------------- | --------- | ----------- | ------------- |
| 경험 기반 | 전문가 판단 | 전문가 경험을 통해 비용을 산정한다 | 주관적이다     | 빠른 산정이 가능하다 | 편차가 크다        |
| 경험 기반 | 델파이 기법 | 다수 전문가 의견을 반복 수렴한다  | 익명성 보장    | 편향을 줄인다     | 시간 소요가 크다     |
| 규모 기반 | LOC    | 코드 라인 수로 비용을 산정한다   | 언어 의존적이다  | 계산이 단순하다    | 초기 단계 적용이 어렵다 |
| 규모 기반 | 기능점수   | 사용자 기능 수로 비용을 산정한다  | 언어 독립적이다  | 초기 산정 가능하다  | 평가가 복잡하다      |
| 모델 기반 | COCOMO | 수학적 모델로 비용을 계산한다    | 경험 데이터 기반 | 체계적이다       | LOC 예측이 어렵다   |

# 3. 비용산정 방식 비교 표

| 구분     | 하향식     | 상향식      |
| ------ | ------- | -------- |
| 산정 순서  | 전체 → 세부 | 세부 → 전체  |
| 적용 시점  | 초기 단계   | 설계 완료 이후 |
| 정확도    | 낮다      | 높다       |
| 소요 시간  | 짧다      | 길다       |
| 관리 용이성 | 높다      | 낮다       |

---

# 4. CPM vs PERT 비교 표

| 구분     | CPM       | PERT     |
| ------ | --------- | -------- |
| 시간 개념  | 확정 시간     | 확률 시간    |
| 입력 값   | 단일 시간     | O, M, P  |
| 초점     | 일정·비용 최적화 | 불확실성 관리  |
| 계산 난이도 | 낮다        | 높다       |
| 활용 분야  | 안정적 프로젝트  | 불확실 프로젝트 |

---

# 5. 일정계획과 비용산정 관계 요약 표

| 항목    | 내용              |

## 비용산정기법 비교 표

| 구분       | 하향식 비용산정                        | 상향식 비용산정              | 수학적 비용산정              |
| -------- | ------------------------------- | --------------------- | --------------------- |
| 기본 개념    | 전체 시스템 비용을 먼저 산정한 후 세부 작업에 배분한다 | 세부 작업별 비용을 산정한 후 합산한다 | 수학적 모델과 공식으로 비용을 산정한다 |
| 산정 기준    | 유사 프로젝트 경험, 전체 규모               | 모듈·작업 단위              | LOC, 기능점수, 보정 계수      |
| 적용 시점    | 프로젝트 초기 단계                      | 상세 설계 이후              | 요구사항 또는 설계 단계         |
| 정확도      | 낮다                              | 높다                    | 비교적 높다                |
| 산정 속도    | 빠르다                             | 느리다                   | 보통이다                  |
| 복잡도      | 낮다                              | 높다                    | 중간~높다                 |
| 주관성      | 높다                              | 중간                    | 낮다                    |
| 대표 기법    | 전문가 판단, 델파이 기법                  | WBS 기반 산정             | COCOMO, 기능점수          |
| 장점       | 빠른 의사결정이 가능하다                   | 현실적인 비용 산정이 가능하다      | 정량적이고 체계적이다           |
| 단점       | 세부 반영이 어렵다                      | 시간과 노력이 많이 든다         | 모델 가정에 의존한다           |
| 적합한 프로젝트 | 소규모·초기 프로젝트                     | 대규모·복잡 프로젝트           | 중대형·표준화 프로젝트          |

---

## 한 줄 정리
* WBS는 필요한 업무와 활동을 세분화 하는 작업
* 하향식은 **빠르지만 거칠다**.
* 상향식은 **느리지만 정확하다**.
* 수학적 기법은 **모델 기반으로 균형 잡힌 산정 방식이다**.
