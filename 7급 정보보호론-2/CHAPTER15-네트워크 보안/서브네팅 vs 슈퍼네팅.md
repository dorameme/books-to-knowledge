
# 서브네팅(Subnetting)과 슈퍼네팅(Supernetting)의 이해

## 1. 서브네팅 (Subnetting)

서브네팅은 하나의 큰 네트워크 주소 범위를 여러 개의 작은 네트워크로 분할하는 과정을 의미한다.

### 특징 및 원리

* 호스트 비트(Host ID)의 일부를 네트워크 비트(Subnet ID)로 전환하여 네트워크를 세분화한다.
* 할당된 서브넷 마스크의 길이는 더 길어진다. (예: /24 -> /26)
* 네트워크를 쪼갤 때마다 네트워크 주소와 브로드캐스트 주소가 새로 생성되므로, 실제 할당 가능한 총 IP 개수는 소폭 감소한다.

### 목적

* IP 주소의 낭비를 방지하고 효율적으로 배분한다.
* 네트워크 간 트래픽을 격리하여 성능을 향상시킨다.
* 특정 네트워크 영역에 대한 보안 관리가 용이해진다.

## 2. 슈퍼네팅 (Supernetting)

슈퍼네팅은 여러 개의 작은 네트워크 주소들을 하나의 큰 네트워크 주소로 통합하는 과정을 의미한다.

### 특징 및 원리

* 네트워크 비트(Network ID)의 일부를 호스트 비트로 전환하여 여러 대역을 묶는다.
* 서브넷 마스크의 길이는 더 짧아진다. (예: /24 -> /22)
* CIDR(Classless Inter-Domain Routing) 기술의 핵심이며 경로 요약(Route Summarization)에 사용된다.

### 목적

* 라우터의 라우팅 테이블 크기를 줄여 메모리 부하를 경감시킨다.
* 네트워크 업데이트 트래픽을 줄여 전체적인 라우팅 효율을 높인다.

## 3. 비교 요약

| 항목 | 서브네팅 | 슈퍼네팅 |
| --- | --- | --- |
| 개념 | 네트워크 분할 | 네트워크 통합 |
| 비트 변경 | Host -> Network | Network -> Host |
| 마스크 길이 | 증가 (길어짐) | 감소 (짧아짐) |
| 주요 용도 | 조직 내 자원 배분 | 경로 요약 및 라우팅 최적화 |
