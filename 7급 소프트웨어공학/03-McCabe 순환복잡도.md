## McCabe 순환복잡도 계산
맥케이브 순환 복잡도(Cyclomatic Complexity)를 구하는 핵심은 **'덩어리'가 아닌 '판단 키워드'를 하나씩 세는 것**이다. 

---

### 1. 핵심 계산 공식

복잡하게 그래프를 그리지 않아도 아래 약식 공식을 사용하면 빠르게 계산할 수 있다.

* **판단 키워드:** 코드의 흐름을 갈라지게 만드는 모든 단어.
* **+1:** 프로그램의 기본적인 실행 경로(Main Path).

### 2. 키워드별 카운트 기준

가장 혼동하기 쉬운 `else if`, `else`, `loop`의 처리 기준이다.

* **무조건 +1 하는 것:**
* `if`, `else if` (각각 독립적인 판단으로 간주)
* `for`, `while`, `do-while` (반복 여부를 판단하므로 포함)
* `case` (switch 문 내부의 각 경우의 수)
* `&&`, `||` (조건식 내부에 있는 논리 연산자도 분기로 취급)
* `catch` (예외 발생 시 분기되므로 포함)


* **세지 않는 것 (0점):**
* `else` (새로운 조건이 아니라 남은 경로일 뿐임)
* `default` (else와 동일한 논리)
* `try`, `finally`



### 3. 예시 사례 분석

질문한 **`if ~ else if ~ else` + `if ~ else` + `while**` 구조의 정확한 계산 과정이다.

**코드 구조 분해**

1. **`if`** ... : **+1** (첫 번째 판단)
2. **`else if`** ... : **+1** (두 번째 판단, 독립적으로 셈)
3. `else` : **0** (무시)
4. **`if`** ... : **+1** (세 번째 판단)
5. `else` : **0** (무시)
6. **`while`** ... : **+1** (네 번째 판단, 반복문)

**최종 계산**

* 키워드 합계: 4개
* 기본 점수: 1점
* **총 복잡도: 5**
