
## 1. 개념

케르베로스는 대칭키 암호를 기반으로 한 중앙 집중식 인증 프로토콜이다.       
네트워크 상에서 사용자의 비밀번호를 직접 전송하지 않고, 티켓(ticket)을 사용하여 사용자를 인증한다.       
주 목적은 신원 인증(authentication)이며, 기밀성·무결성을 보조적으로 제공한다.        

클라이언트와 서버가 서로를 신뢰하지 않는 환경에서, 신뢰 가능한 제3자(KDC)를 통해 인증을 수행한다.

---

## 2. 구성 요소

| 구성 요소  | 설명                                       |
| ------ | ---------------------------------------- |
| Client | 인증을 요청하는 사용자 또는 프로그램이다                   |
| Server | 서비스를 제공하는 서버이다                           |
| KDC    | 인증을 담당하는 중앙 서버이다                         |
| AS     | Authentication Server, 최초 사용자 인증을 담당한다   |
| TGS    | Ticket Granting Server, 서비스 접근용 티켓을 발급한다 |
| Ticket | 인증 정보를 담은 암호화된 데이터이다                     |

AS와 TGS는 일반적으로 KDC 내부에 함께 존재한다.

---

## 3. 동작 흐름

### 1단계: 사용자 인증 (AS 단계)

* 사용자는 자신의 ID를 AS에 전송한다
* AS는 사용자 비밀번호 기반 키로 암호화된 TGT(Ticket Granting Ticket)를 발급한다

### 2단계: 서비스 티켓 요청 (TGS 단계)

* 사용자는 TGT를 TGS에 제출한다
* TGS는 특정 서비스 서버에 접근하기 위한 Service Ticket을 발급한다

### 3단계: 서비스 접근

* 사용자는 Service Ticket을 서버에 전달한다
* 서버는 티켓을 검증하고 서비스 접근을 허용한다

비밀번호는 네트워크에 직접 전송되지 않는다.

---

## 4. 보안적 특징

| 항목        | 설명                    |
| --------- | --------------------- |
| 인증 방식     | 대칭키 기반 티켓 인증이다        |
| 비밀번호 노출   | 네트워크 상에 노출되지 않는다      |
| 재전송 공격 방어 | 타임스탬프 사용으로 방지한다       |
| 상호 인증     | 클라이언트와 서버 상호 인증이 가능하다 |
| 중앙 집중식    | KDC에 의존한다             |

---

## 5. 예시

### 실제 환경 예시

* 기업 내부 사내망 로그인 시스템이다
* 대학교 포털 로그인 시스템이다
* Active Directory 기반 윈도우 도메인 인증이다

### 상황 예시

* 사용자가 회사 PC에 로그인한다
* 로그인 시 비밀번호는 KDC와만 공유된다
* 이후 파일 서버, 메일 서버 접근 시 추가 로그인 없이 티켓으로 인증한다

이는 SSO(Single Sign-On)를 구현한 사례이다.

---

## 6. 장점과 단점

| 구분 | 내용                   |
| -- | -------------------- |
| 장점 | 비밀번호 직접 전송이 없다       |
|    | 재전송 공격에 강하다          |
|    | SSO 구현이 가능하다         |
| 단점 | KDC 장애 시 전체 인증이 불가하다 |
|    | 시간 동기화가 필수이다         |
|    | 초기 설정과 관리가 복잡하다      |

---

## 7. 다른 인증 방식과 비교

| 구분    | Kerberos | 공개키 기반 인증 |
| ----- | -------- | --------- |
| 기반 암호 | 대칭키      | 공개키       |
| 중앙 서버 | 필수       | 선택        |
| 계산 비용 | 낮다       | 높다        |
| 사용 환경 | 내부 네트워크  | 인터넷 환경    |

---

## 8. 핵심 요약

* 케르베로스는 대칭키 기반 중앙 인증 프로토콜이다
* 티켓을 사용하여 비밀번호 노출을 방지한다
* 타임스탬프를 이용해 재전송 공격을 방어한다
* 내부망, 기업 환경, 도메인 인증에 널리 사용된다
