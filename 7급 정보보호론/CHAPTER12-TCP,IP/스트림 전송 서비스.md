## 스트림 전송 서비스
데이터를 연속된 흐름(stream)로 보장하며 전달하는 전송 방식이다.

---

## 1. 스트림 전송 서비스 개념

스트림 전송 서비스는
데이터의 경계가 보이지 않게,
마치 물이 흐르듯 연속적인 바이트 흐름으로 전달한다.

* 메시지 단위가 아니다
* 바이트 단위 전송이다

---

## 2. 대표 프로토콜

* TCP가 스트림 전송 서비스를 제공한다

---

## 3. 스트림 전송의 핵심 특징

| 특징    | 의미          |
| ----- | ----------- |
| 연결 지향 | 송수신 연결 후 전송 |
| 순서 보장 | 보낸 순서대로 도착  |
| 신뢰성   | 손실 시 재전송    |
| 경계 없음 | 메시지 구분 안 함  |

---

## 4. 왜 스트림 전송이 필요한가

* 파일 전송
* 웹 페이지 로딩
* 데이터 무결성이 중요한 통신

데이터가 깨지거나 순서가 바뀌면 안 된다.

---

## 5. 스트림 vs 메시지 전송

| 구분      | 스트림    | 메시지    |
| ------- | ------ | ------ |
| 데이터 단위  | 바이트 흐름 | 메시지 단위 |
| 경계      | 없음     | 있음     |
| 대표 프로토콜 | TCP    | UDP    |

---

## 6. 비유

* 스트림 전송: 수도관으로 흐르는 물이다
* 메시지 전송: 박스 단위 택배이다

물은 중간 경계가 없다.

---

## 7. 실무 관점

* HTTP/HTTPS 기본은 TCP 스트림이다
* 애플리케이션이 직접 메시지 경계를 정의해야 한다

---

## 8. 한 줄 요약

스트림 전송 서비스는 데이터를 끊김 없는 바이트 흐름으로 전달하는 신뢰성 전송 방식이다.
