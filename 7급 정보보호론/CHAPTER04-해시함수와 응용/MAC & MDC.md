

## 1. MDC는 해시 기반이다

MDC의 정의 자체가 해시이다.

* MDC = 암호학적 해시 함수의 출력
* 키 없음
* 단방향성

예:

* SHA-256
* SHA-3
* MD5

➡️ MDC는 **항상 해시 기반**이다.

---

## 2. MAC은 해시 기반일 수도, 아닐 수도 있다

MAC은 **구현 방식에 따라 다르다.**

### 해시 기반 MAC

* HMAC
* KMAC

```
MAC = Hash(K || M || ...)
```

---

### 블록암호 기반 MAC

* CMAC
* CBC-MAC
* GMAC

```
MAC = Enc_K(M)
```

---

### 스트림/특수 구조 기반 MAC

* Poly1305
* UMAC

---

## 3. 핵심 비교 정리

| 구분    | MDC | MAC      |
| ----- | --- | -------- |
| 해시 기반 | 항상  | 경우에 따라   |
| 키 사용  | 없음  | 있음       |
| 목적    | 무결성 | 무결성 + 인증 |

---

## 4. 한 줄 결론

* MDC는 정의상 해시 기반이다
* MAC은 해시 기반일 수도 있고 아닐 수도 있다
