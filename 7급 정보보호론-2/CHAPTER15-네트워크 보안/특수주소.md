

### 1. 디스 호스트 주소 (This Host Address)

**주소: 0.0.0.0**

* **정의:** 네트워크에서 자신의 IP를 아직 할당받지 못한 호스트가 '나 자신'을 지칭할 때 사용하는 주소이다.
* **용도:** 주로 DHCP 요청 시 패킷의 **발신지(Source) 주소**로 사용한다.
* **특징:** 물리적인 주소가 아니며, 이 주소를 목적지로 삼아 패킷을 보낼 수는 없다.

### 2. 루프백 주소 (Loopback Address)

**주소: 127.0.0.1 ~ 127.255.255.254 (주로 127.0.0.1 사용)**

* **정의:** 외부로 패킷을 보내지 않고 자기 자신에게 데이터를 다시 돌려보내기 위해 예약된 주소이다.
* **용도:** 자신의 네트워크 소프트웨어나 서비스가 정상 작동하는지 테스트할 때 사용한다.
* **특징:** 이 주소로 보낸 패킷은 네트워크 카드(NIC) 외부로 나가지 않고 운영체제 내부에서 즉시 처리된다. `localhost`라는 호스트명과 동일한 의미를 가진다.

### 3. 제한된 브로드캐스트 주소 (Limited Broadcast Address)

**주소: 255.255.255.255**

* **정의:** 현재 접속된 로컬 네트워크(LAN) 내의 모든 호스트에게 메시지를 보내기 위한 주소이다.
* **용도:** 상대방의 IP를 모르는 상태에서 같은 망 안의 모든 장비에 패킷을 뿌릴 때 **목적지(Destination) 주소**로 사용한다.
* **특징:** 라우터에 의해 차단되므로 다른 네트워크 대역으로는 패킷이 전달되지 않는다.

### 4. 직접적 브로드캐스트 주소 (Directed Broadcast Address)

**주소: [Network ID].255 (예: 172.16.0.255)**

* **정의:** 내가 속하지 않은 '특정 외부 네트워크'의 모든 호스트를 대상으로 패킷을 보내기 위한 주소이다.
* **용도:** 원격지 네트워크 전체에 데이터를 전송해야 할 때 사용한다.
* **특징:** 목적지 네트워크의 라우터까지는 일반 패킷처럼 전달되지만, 도착 후 해당 네트워크 내부 전체로 뿌려진다. 보안 취약성(DDoS 악용 등)으로 인해 실제 환경에서는 대부분 차단한다.

### 💡 4개 주소 한눈에 비교

| 구분 | 주소 형태 | 주요 역할 | 전송 범위 |
| --- | --- | --- | --- |
| **디스 호스트** | 0.0.0.0 | IP 할당 전의 발신자 표시 | 자기 자신(논리적) |
| **루프백** | 127.0.0.1 | 네트워크 기능 자가 테스트 | 자기 자신(내부적) |
| **제한된 브로드캐스트** | 255.255.255.255 | 현재 로컬 망 전체 공지 | 동일 LAN 세그먼트 |
| **직접적 브로드캐스트** | Network ID.255 | 원격지 특정 망 전체 공지 | 특정 외부 네트워크 |
