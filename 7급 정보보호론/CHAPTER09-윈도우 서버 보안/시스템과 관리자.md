

# 1. 시스템(System) 계정

## 1-1. 개념

* 시스템 계정은 **운영체제 자체가 사용하는 내부 계정**이다.
* OS 핵심 서비스와 프로세스를 실행할 때 사용된다.
* 일반 사용자가 로그인할 수 없고, 화면에 나타나지 않는다.

---

## 1-2. 특징

* 모든 파일과 레지스트리에 접근 가능
* 네트워크 및 하드웨어 장치까지 제어 가능
* 운영체제 자체 작업 전용 계정

---

## 1-3. 사용 예시

* Windows Update 서비스
* 백업 및 복원 서비스
* 시스템 프로세스 실행(Explorer, svchost 등)

---

## 1-4. 장점

* OS 안정성 보장
* 핵심 시스템 작업 수행 가능

---

## 1-5. 단점

* 권한이 너무 높아서 잘못된 조작 시 시스템 전체 손상 가능
* 일반 사용자가 직접 접근 불가

---

# 2. 관리자(Administrator) 계정

## 2-1. 개념

* 관리자는 **사용자가 직접 로그인 가능한 최고 권한 계정**이다.
* 파일 설치, 프로그램 실행, 계정 추가 등 시스템 설정 변경 가능

---

## 2-2. 특징

* OS 기본 제공 계정 중 하나
* 대부분 GUI 환경에서 사용 가능
* 사용자 권한 계층에서 가장 높은 권한

---

## 2-3. 사용 예시

* 프로그램 설치/삭제
* 네트워크 설정 변경
* 사용자 계정 추가/삭제
* 레지스트리 수정

---

## 2-4. 장점

* 시스템 관리와 설정 변경 가능
* 소프트웨어 설치/제거 용이

---

## 2-5. 단점

* 권한 남용 시 보안 위험
* 악성코드가 관리자 권한으로 실행되면 피해 커짐

---

# 3. 시스템과 관리자 비교

| 구분    | 시스템(System)          | 관리자(Administrator) |
| ----- | -------------------- | ------------------ |
| 접근    | 일반 사용자 로그인 불가        | 로그인 가능             |
| 권한 범위 | OS 전체, 모든 서비스와 파일 접근 | 대부분 시스템 영역 접근 가능   |
| 주 용도  | 운영체제 내부 프로세스 실행      | 사용자 시스템 관리 및 설정    |
| GUI   | 없음                   | 있음                 |
| 위험도   | 잘못 조작 시 OS 손상        | 권한 남용 시 보안 위험      |

---

# 4. 핵심 요약

* **시스템 계정**: OS 자체를 위해 존재, 사용자는 접근 불가, 권한 최상
* **관리자 계정**: 사용자가 직접 로그인 가능, 시스템 설정과 소프트웨어 설치 가능
* 차이: **접근 가능 여부와 사용 대상**이 다르다
