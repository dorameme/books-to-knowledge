

### 1. 디스 호스트 주소 (This Host Address)

**주소: 0.0.0.0**

* **정의:** 네트워크에서 자신의 IP 주소를 아직 할당받지 못한 호스트가 '나 자신'을 지칭하기 위해 사용하는 가상의 주소이다.
* **주요 역할:** DHCP 서버에게 IP 할당을 요청할 때 패킷의 **발신지(Source)** 주소로 기입한다.
* **특징:** 이 주소는 실제 통신용 주소가 아니며, 목적지 주소로 사용할 수 없다.

### 2. 제한된 브로드캐스트 주소 (Limited Broadcast Address)

**주소: 255.255.255.255**

* **정의:** 현재 자신이 속한 로컬 네트워크 내의 모든 호스트에게 메시지를 전달하기 위해 사용하는 주소이다.
* **주요 역할:** 상대방의 IP를 모르는 상태에서 현재 네트워크 전체에 공지 사항을 뿌릴 때 **목적지(Destination)** 주소로 사용한다.
* **특징:** 라우터를 절대 통과할 수 없으므로, 내가 속한 네트워크 밖으로는 패킷이 나가지 않는다.

### 3. 직접적 브로드캐스트 주소 (Directed Broadcast Address)

**주소: [네트워크 주소].255 (예: 192.168.10.255)**

* **정의:** 자신이 속하지 않은 '특정 외부 네트워크'의 모든 호스트를 대상으로 메시지를 전달하기 위한 주소이다.
* **주요 역할:** 원격지에 있는 특정 네트워크 대역 전체에 데이터를 전송할 때 사용한다.
* **특징:** 패킷이 목적지 네트워크의 라우터까지는 유니캐스트처럼 전달되지만, 해당 라우터에 도착하면 그 내부 네트워크 전체로 뿌려진다. 보안상의 이유로 현대 네트워크에서는 대부분 차단되어 있다.

---

### 4. 세 주소의 핵심 비교 요약

| 구분 | 디스 호스트 (0.0.0.0) | 제한된 브로드캐스트 (255.255.255.255) | 직접적 브로드캐스트 (Network.255) |
| --- | --- | --- | --- |
| **의미** | 주소 없는 나 자신 | 우리 동네(로컬) 전체 | 저쪽 동네(원격) 전체 |
| **주요 용도** | 발신지 주소 (IP 요청용) | 목적지 주소 (로컬 공지용) | 목적지 주소 (원격 전송용) |
| **라우터 통과** | 불가능 | **불가능 (차단됨)** | **가능 (목적지까지 전달됨)** |
| **보안 위험** | 없음 | 낮음 | 높음 (공격 매개체로 악용) |
