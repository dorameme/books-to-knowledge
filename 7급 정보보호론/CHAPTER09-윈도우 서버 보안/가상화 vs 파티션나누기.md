

# 1. 파티션 나누기

## 1-1. 개념

파티션 나누기는 **하드디스크 하나를 여러 개의 독립된 공간으로 쪼개는 것**이다.

* 물리적 디스크는 그대로 존재한다.
* 하지만 OS 입장에서는 C:, D:처럼 **각각 다른 드라이브**처럼 보인다.

쉽게 말하면 **하드디스크 안에 가상의 칸막이를 만드는 것**이다.

---

## 1-2. 특징

* 디스크를 여러 용도로 나눌 수 있다.
  예: C:는 OS 설치, D:는 데이터 저장, E:는 백업
* 멀티부팅 환경에서 OS마다 별도 공간 제공 가능
* 하나의 물리 디스크를 나누는 것이므로 **리소스를 새로 만드는 것이 아님**

---

## 1-3. 장점

* 데이터 관리가 편리하다
* OS 재설치 시 다른 파티션 데이터는 보존 가능
* 파일 시스템 충돌 방지 가능

---

## 1-4. 단점

* 물리적 디스크 크기보다 크게 나눌 수 없다
* OS별 격리 수준이 낮다(한 OS 문제 시 다른 파티션 영향 가능)

---

## 1-5. 실제 예시

* C: OS 설치, D: 사진·문서 저장
* 복구 파티션: 제조사에서 제공, OS 복구 용도
* Windows와 Linux를 같은 하드에 설치할 때 파티션 분리

---

# 2. 가상화(Virtualization)

## 2-1. 개념

가상화는 **물리적인 하드웨어 위에 새로운 가상의 컴퓨터 환경을 만드는 것**이다.

* CPU, 메모리, 하드디스크, 네트워크까지
  가상으로 만들어 OS가 독립적으로 돌아가도록 한다.
* 예: 내 컴퓨터(Windows) 안에서 Ubuntu를 설치하고 실행하는 것

---

## 2-2. 특징

* 가상 머신(VM)이라는 별도의 독립 공간 생성
* 물리적 리소스를 일정 부분 나눠 사용
* OS별로 완전히 독립된 환경 제공

---

## 2-3. 장점

* 여러 OS를 동시에 테스트 가능
* OS 충돌 위험 없음
* 복사나 삭제가 쉬움

---

## 2-4. 단점

* 물리적 리소스를 나눠 쓰므로 속도가 느릴 수 있음
* 설정이 조금 복잡함

---

## 2-5. 실제 예시

* Windows에서 VirtualBox로 Ubuntu 설치
* 서버 한 대에 여러 가상 서버 운영
* 개발용 테스트 환경에서 여러 OS 동시 실행

---

# 3. 파티션과 가상화 비교

| 구분    | 파티션                    | 가상화                            |
| ----- | ---------------------- | ------------------------------ |
| 정의    | 하드디스크를 여러 드라이브처럼 나누는 것 | 물리 컴퓨터 위에 별도 가상의 컴퓨터 환경을 만드는 것 |
| 리소스   | 같은 디스크 사용              | 물리 리소스를 일부 나눠 사용               |
| OS 실행 | 물리 OS만 사용 가능           | 별도의 OS 설치 가능, 동시에 여러 OS 가능     |
| 목적    | 데이터 분리, 멀티부팅           | 테스트, 격리 환경, 서버 운영              |
| 장점    | 관리 편리, 멀티부팅 가능         | 독립적 환경, OS 충돌 없음               |
| 단점    | OS 격리 부족               | 리소스 부담, 초기 설정 필요               |

---

# 4. 핵심 차이

* **파티션**은 “하드디스크 안에서 공간을 나누는 것”이다.
* **가상화**는 “하드웨어 전체를 가상으로 만들어 독립적인 컴퓨터 환경을 만드는 것”이다.
* 파티션은 **하드디스크 내부의 논리적 구분**이고,
  가상화는 **새로운 컴퓨터를 만들고 OS까지 독립적으로 돌리는 것**이다.
