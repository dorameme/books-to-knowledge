# 동기식 vs 자기동기식


# 1. 먼저 핵심 구분 기준

**차이는 하나이다.**

> 키스트림 생성에
> **암호문이 들어가느냐 / 안 들어가느냐**

이 기준 하나로 전부 갈린다.

---

# 2. 동기식 스트림 암호 (Synchronous)

## 개념

송신자와 수신자가
같은 키 + 같은 IV(또는 카운터)로
같은 키스트림을 미리 맞춰 놓고 진행한다.

키스트림 생성은
암호문, 평문과 **완전히 독립적**이다.

---

## 구조 요약

```
키스트림 = f(키, IV/카운터)
암호문 = 평문 ⊕ 키스트림
```

---

## 특징

1. 키스트림이 키와 IV에 의해 완전히 결정된다
2. 암호문 오류가 다음 키스트림에 영향을 주지 않는다
3. 오류 전파가 없다
4. 중간에 비트 유실 시 끝까지 어긋난다
5. 동기화 손실이 발생한다

---

## 중요한 구분

* 끝까지 틀어지는 현상은 **오류 전파가 아니다**
* 이는 **동기화 손실**이다

오류는 퍼지지 않고
위치만 어긋난다.

---

## 대표 모드

* OFB
* CTR
* GCM

---

## 실무 비유

같은 난수표를 들고
같은 줄을 동시에 읽는다.
상대가 뭘 말했는지는 보지 않는다.

---

# 3. 자기동기식 스트림 암호 (Self-synchronizing)

## 개념

수신자가
**이전 암호문을 이용해 키스트림을 생성**한다.

암호문이 키스트림 생성에 직접 관여한다.

---

## 구조 요약

```
키스트림 = f(키, 이전 암호문)
암호문 = 평문 ⊕ 키스트림
```

---

## 특징

1. 키스트림이 암호문에 의존한다
2. 암호문 오류가 키스트림에 영향을 준다
3. 오류가 몇 블록 전파된다
4. 일정 구간 후 자동으로 다시 맞춰진다
5. 동기화 복구가 가능하다

---

## 대표 모드

* CFB

---

## 실무 비유

상대가 방금 한 말을 듣고
다음 말을 이어간다.
잠깐 틀려도 다시 맞춰진다.

---

# 4. 오류 전파 vs 동기화 손실 정리

| 구분     | 의미                    |
| ------ | --------------------- |
| 오류 전파  | 한 비트 오류가 여러 비트 오류로 확산 |
| 동기화 손실 | 위치가 어긋나 계속 틀어짐        |

---

## 적용

| 방식    | 오류 전파 | 동기화 손실 |
| ----- | ----- | ------ |
| 동기식   | 없음    | 있음     |
| 자기동기식 | 있음    | 없음     |

---

# 5. 용어 혼동 정리

* 비동기식 스트림 암호라는 표현은 혼동 용어이다
* 실제로는 대부분 **자기동기식**을 의미한다
* 정확한 분류는
  **동기식 / 자기동기식** 두 가지이다

---

# 6. 한 문장 요약 (시험용)

* **동기식**
  키와 IV로 미리 맞추며 오류는 퍼지지 않는다

* **자기동기식**
  암호문을 보고 다시 맞추며 오류는 전파된다

---

## 최종 한 문장 결론

**동기식은 같이 출발하고,
자기동기식은 따라가며 맞춘다.**

여기까지 이해했으면
이 파트는 완전히 끝이다.
