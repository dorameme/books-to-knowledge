

## 1. 보안 모델 개요

| 모델     | 핵심 목표             |
| ------ | ----------------- |
| 벨라-파듈라 | 기밀성 보호            |
| 비바     | 무결성 보호            |
| 클락–윌슨  | 상업 시스템 무결성 보호     |
| 라티스    | 기밀성과 무결성의 수학적 구조화 |

---

## 2. 모델별 상세 설명

### 1) 벨라-파듈라 모델 (Bell–LaPadula Model)

**목적**
정보의 **기밀성(Confidentiality)** 을 보장한다.

**핵심 개념**
군사 보안 모델로, 정보가 **낮은 등급으로 유출되는 것**을 방지한다.

**보안 규칙**

* No Read Up
  자신보다 높은 보안 등급의 정보는 읽을 수 없다.
* No Write Down
  자신보다 낮은 보안 등급으로 정보를 쓸 수 없다.

**특징**

* 읽기와 쓰기를 명확히 구분한다.
* 무결성은 고려하지 않는다.
* 정보 유출 방지에 최적화되어 있다.

**적용 분야**

* 군사 시스템
* 국가 기밀 관리 시스템

---

### 2) 비바 모델 (Biba Model)

**목적**
정보의 **무결성(Integrity)** 을 보장한다.

**핵심 개념**
벨라-파듈라의 개념을 **정반대로 적용**한 모델이다.

**보안 규칙**

* No Read Down
  자신보다 낮은 무결성 등급의 정보는 읽을 수 없다.
* No Write Up
  자신보다 높은 무결성 등급으로 정보를 쓸 수 없다.

**특징**

* 오염된 데이터가 상위로 전파되는 것을 방지한다.
* 기밀성은 고려하지 않는다.
* 데이터 정확성과 신뢰성이 핵심이다.

**적용 분야**

* 금융 데이터 처리
* 회계 시스템

---

### 3) 클락–윌슨 모델 (Clark–Wilson Model)

**목적**
**상업 환경에서의 무결성**을 보장한다.

**핵심 개념**

* 사용자의 직접 접근을 금지한다.
* 반드시 **정의된 절차(트랜잭션)** 를 통해서만 데이터에 접근한다.

**주요 요소**

* CDI (Constrained Data Item)
  보호 대상 데이터이다.
* UDI (Unconstrained Data Item)
  외부 입력 데이터이다.
* TP (Transformation Procedure)
  데이터를 변경하는 검증된 절차이다.
* IVP (Integrity Verification Procedure)
  무결성 검증 절차이다.

**특징**

* 현실적인 업무 흐름을 반영한다.
* 역할 기반 접근 제어와 잘 어울린다.
* 내부자 공격 방어에 강하다.

**적용 분야**

* 은행 전산 시스템
* 기업 ERP 시스템

---

### 4) 라티스 모델 (Lattice-Based Model)

**목적**
**기밀성과 무결성을 수학적으로 동시에 표현**한다.

**핵심 개념**

* 모든 보안 등급과 권한을 **부분 순서 집합(Lattice)** 으로 표현한다.
* 접근 제어 결정을 수학적으로 판단한다.

**특징**

* 벨라-파듈라와 비바를 포함하는 상위 개념이다.
* 접근 제어가 형식적으로 엄밀하다.
* 구현 복잡도가 높다.

**적용 분야**

* 고신뢰 시스템
* 보안 정책 검증용 이론 모델

## 3. 핵심 비교 표

| 구분     | 벨라-파듈라        | 비바           | 클락–윌슨    | 라티스     |
| ------ | ------------- | ------------ | -------- | ------- |
| 주요 목표  | 기밀성           | 무결성          | 상업적 무결성  | 기밀성·무결성 |
| 보호 대상  | 정보 유출         | 데이터 오염       | 업무 데이터   | 정책 전체   |
| 접근 방식  | 등급 기반         | 등급 기반        | 절차 기반    | 수학적 관계  |
| 읽기 규칙  | No Read Up    | No Read Down | TP 통해 접근 | 정책 정의   |
| 쓰기 규칙  | No Write Down | No Write Up  | TP 통해 접근 | 정책 정의   |
| 현실 반영성 | 낮음            | 낮음           | 높음       | 낮음      |
| 내부자 통제 | 약함            | 약함           | 강함       | 정책 의존   |
| 대표 환경  | 군사            | 금융 무결성       | 기업 시스템   | 이론·검증   |

## 4. 한 줄 요약

* 벨라-파듈라는 **정보를 새지 않게 하는 모델**이다.
* 비바는 **정보가 더러워지지 않게 하는 모델**이다.
* 클락–윌슨은 **사람의 실수와 악의를 절차로 통제하는 모델**이다.
* 라티스는 **이 모든 것을 수학적으로 묶는 상위 개념 모델**이다.

1. 벨라-파듈라 = MAC + 기밀성
2. 비바 = MAC + 무결성
3. 클락-윌슨 = RBAC + 상업 무결성
4. 라티스 = MAC + 수학적 보안 구조
