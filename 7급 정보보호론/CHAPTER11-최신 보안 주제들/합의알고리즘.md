

## 1. 합의 알고리즘이란

**합의 알고리즘**은
분산된 노드들이 **어떤 블록이 진짜인지 동일하게 합의하기 위한 규칙**이다.

* 중앙 관리자 없음
* 일부 노드가 악의적이어도 전체 신뢰 유지가 목적이다

---

## 2. PoW (Proof of Work)

### 개념

* **연산 작업을 가장 먼저 해결한 노드가 블록 생성 권한을 얻는다**
* 작업 증명을 통해 신뢰를 확보한다

### 의미

* “실제로 많은 계산을 했다는 사실”이 신뢰 근거이다
* 계산 비용이 공격 비용이 된다

### 동작 방식

1. 노드가 해시 퍼즐 계산
2. 정답을 가장 먼저 찾은 노드가 블록 생성
3. 다른 노드가 검증 후 체인에 추가

### 실무 활용

* 비트코인
* 보안 안정성 최우선 네트워크
* 초기 블록체인 구조

---

## 3. PoS (Proof of Stake)

### 개념

* **보유한 코인 지분(stake)에 따라 블록 생성 권한을 부여한다**
* 연산이 아니라 자산 보유가 기준이다

### 의미

* 많이 걸수록(예치할수록) 책임도 커진다
* 네트워크 파괴 시 본인 자산이 손해를 본다

### 동작 방식

1. 코인을 예치한 노드 중 선택
2. 선택된 노드가 블록 생성
3. 부정행위 시 예치 자산 삭감(slashing)

### 실무 활용

* 이더리움(전환 완료)
* 친환경, 확장성 중시 네트워크
* 대규모 트랜잭션 처리

---

## 4. 핵심 비교 표

| 구분    | PoW     | PoS        |
| ----- | ------- | ---------- |
| 합의 기준 | 연산 능력   | 지분(코인 보유량) |
| 자원 소모 | 매우 큼    | 매우 적음      |
| 보안 방식 | 공격 비용 ↑ | 자산 손실 위험   |
| 처리 속도 | 느림      | 빠름         |
| 환경 영향 | 큼       | 작음         |
| 대표 사례 | 비트코인    | 이더리움       |

---

## 5. 실무 관점 선택 기준

* **보안·불변성 최우선** → PoW
* **속도·확장성·친환경** → PoS
* 최신 퍼블릭 체인은 대부분 PoS 계열을 채택한다

---

## 6. 한 줄 정리

* **PoW**는 “계산을 많이 한 사람이 신뢰받는다”
* **PoS**는 “자산을 걸고 책임지는 사람이 신뢰받는다”

---
## PoW -> PoS?

이유는 단순하다. **퍼블릭 체인이 커지면 PoW는 구조적으로 버티기 어렵기 때문**이다.
핵심 이유만 정확히 정리한다.

---

## 1. 에너지·비용 문제

* PoW는 **보안 = 연산량**이다
* 네트워크가 커질수록

  * 전기 소모 폭증
  * 채굴 장비 비용 증가
* 사회적·정책적 압박이 커졌다

  * ESG, 탄소 규제, 전력 낭비 이슈

→ 대규모 퍼블릭 체인에 부적합하다

---

## 2. 확장성 한계

* PoW는 블록 생성 속도를 쉽게 올릴 수 없다
* TPS 증가 = 보안 약화 위험
* 실제 서비스 수준 트랜잭션 처리에 한계가 있다

→ 디파이, NFT, 결제 서비스에 불리하다

---

## 3. 중앙화 문제 (역설)

* PoW는 이론상 탈중앙화지만
* 현실에서는

  * 채굴 풀 집중
  * 대형 채굴장 독점
* 결국 **자본이 많은 쪽으로 중앙화**된다

→ 퍼블릭 체인의 이상과 어긋난다

---

## 4. PoS의 구조적 장점

* 연산 경쟁 없음 → 에너지 거의 소모 없음
* 블록 생성 속도 빠름
* 하드웨어 진입 장벽 낮음
* 악의 행위 시 **자산 직접 손실(slashing)**

→ 보안·효율·확장성 균형이 맞는다

---

## 5. 실무적 결정 요인

| 관점       | PoW | PoS |
| -------- | --- | --- |
| 운영 비용    | 높음  | 낮음  |
| 환경 규제 대응 | 어려움 | 쉬움  |
| 서비스 확장   | 불리  | 유리  |
| 생태계 확장   | 느림  | 빠름  |

---

## 6. 결론 한 줄

> **퍼블릭 체인은 이제 ‘실제 서비스 운영’이 목적이므로,
> 비용·속도·확장성에서 유리한 PoS를 선택할 수밖에 없다.**

비트코인은 **가치 저장·불변성 특화**라 PoW를 유지하는 예외다.
