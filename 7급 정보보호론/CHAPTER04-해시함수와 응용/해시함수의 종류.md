## 해시함수

해시함수는 크게 **키가 없는 해시함수**와 **키를 사용하는 해시함수**로 나눌 수 있다.

## 1. 키가 없는 해시함수 (Keyless Hash Function)

### 개념

입력값을 고정 길이의 해시값으로 변환하는 함수이다. 입력값과 상관없이 일정한 길이의 출력을 만들어 주며, 같은 입력이면 항상 같은 출력이 나온다. 키를 사용하지 않기 때문에 누구나 같은 입력에 대해 같은 결과를 얻는다.

### 사용

* 데이터 무결성 검증: 파일이 전송 중 변조되었는지 확인한다.
* 디지털 서명: 해시값을 기반으로 서명을 생성한다.
* 비밀번호 저장: 비밀번호를 해시값으로 저장하여 원본 노출을 방지한다.

### 대표적인 종류

* **MD5**: 128비트 해시, 빠르지만 충돌 가능성이 있어 보안에는 취약하다.
* **SHA-1**: 160비트 해시, 과거에 많이 쓰였으나 충돌 가능성 때문에 현대에는 잘 쓰이지 않는다.
* **SHA-2 (SHA-256, SHA-512 등)**: 256~512비트 해시, 현재 많이 사용되는 안전한 해시이다.
* **SHA-3**: SHA-2 대안, 구조가 다르며 강력한 보안성을 제공한다.

## 2. 키를 사용하는 해시함수 (Keyed Hash Function, MAC)

### 개념

입력값과 비밀키를 함께 사용하여 해시값을 만든다. 키를 모르는 공격자는 동일한 해시값을 계산할 수 없으므로 인증과 무결성을 동시에 제공한다.

### 사용

* 메시지 인증 코드(MAC) 생성: 송신자가 보낸 메시지가 변조되지 않았고, 인증된 송신자가 보냈음을 확인한다.
* 데이터 무결성 + 인증: 단순 키 없는 해시함수보다 안전하게 사용된다.

### 대표적인 종류

* **HMAC (Hash-based Message Authentication Code)**: SHA 계열 해시함수를 기반으로 키와 함께 MAC 생성
* **CMAC (Cipher-based Message Authentication Code)**: 블록 암호 기반 MAC, AES와 함께 사용 가능
* **UMAC/VMAC**: 빠른 성능을 강조한 MAC, 고속 네트워크 환경에서 사용

## 3. 비교 표

| 구분           | 개념                   | 사용                          | 대표 예                     |
| ------------ | -------------------- | --------------------------- | ------------------------ |
| 키가 없는 해시함수   | 입력값을 고정 길이로 변환, 키 없음 | 데이터 무결성 검증, 디지털 서명, 비밀번호 저장 | MD5, SHA-1, SHA-2, SHA-3 |
| 키를 사용하는 해시함수 | 입력값 + 비밀키를 이용해 해시 생성 | 메시지 인증, 데이터 무결성 + 인증        | HMAC, CMAC, UMAC, VMAC   |
