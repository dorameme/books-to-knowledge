

### 1. PPP (Point-to-Point Protocol)

* **계층:** 데이터 링크 계층 (2계층)
* **용도:** 두 지점을 **직접(물리적으로)** 연결할 때 사용한다.
* **특징:** 과거 전화선 모뎀 접속이나 전용선 연결에서 데이터를 캡슐화하고 사용자 인증(PAP/CHAP)을 수행하는 기본 프로토콜이다.
* **한계:** 암호화 기능이 없으며, 물리적으로 직접 연결된 구간에서만 작동한다.

### 2. PPTP (Point-to-Point Tunneling Protocol)

* **계층:** 전송/응용 계층 (구현에 따라 다르나 보통 3계층 터널링으로 분류)
* **용도:** 인터넷과 같은 공용망을 통해 **VPN(가상 사설망)**을 구축할 때 사용한다.
* **특징:** **PPP 프레임을 IP 패킷 안에 집어넣어(터널링)** 전송한다. 즉, 멀리 떨어진 지점 간에도 마치 직접 연결된 PPP처럼 동작하게 만든다.
* **보안:** MS-CHAP 인증과 MPPE(Microsoft Point-to-Point Encryption) 암호화를 추가하여 보안성을 높였다.

---

### 3. 주요 차이점 비교

| 구분 | PPP | PPTP |
| --- | --- | --- |
| **기본 개념** | 1:1 직접 연결 프로토콜 | VPN 터널링 프로토콜 |
| **연결 매체** | 전화선, 전용선 (물리적 연결) | 인터넷 (IP 망) |
| **구성 방식** | 데이터 캡슐화 | **PPP를 IP 패킷 속에 넣음 (Encapsulation)** |
| **암호화** | 없음 | 지원 (MPPE 등) |
| **관계** | 기반 기술 | **PPP를 활용한 응용 기술** |

---

### 4. 핵심 요약

* **PPP**는 데이터를 담는 **'그릇'**이자 인증 절차다.
* **PPTP**는 그 PPP라는 그릇을 **'IP 패킷'이라는 택배 상자**에 넣어 인터넷으로 멀리 보내는 **VPN 기술**이다.

**결론**
PPTP는 내부적으로 PPP의 인증 및 제어 기능을 그대로 가져다 쓰면서, 인터넷상에서 안전하게 데이터를 주고받기 위해 암호화와 터널링을 더한 형태라고 이해하면 된다.

현재는 PPTP의 보안 취약성 때문에 L2TP/IPsec이나 OpenVPN, WireGuard 등을 더 많이 사용한다. 이 중 현대적인 VPN 프로토콜들의 차이점이 궁금한가?
