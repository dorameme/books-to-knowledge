

## 1. 타이밍 공격(시간 공격, Timing Attack)
- 타이밍 공격은 암호 구현의 시간 차이를 관찰해 비밀키를 조금씩 추론하는 사이드채널 공격이다.

| 구분    | 내용                                               |
| ----- | ------------------------------------------------ |
| 개념    | 암호 연산에 걸리는 시간 차이를 분석하여 비밀 정보를 추론하는 공격이다          |
| 공격 원리 | 조건 분기, 반복 횟수, 캐시 히트 여부 등에 따라 연산 시간이 달라지는 점을 이용한다 |
| 주요 대상 | RSA 개인키 연산, AES 테이블 기반 구현, 패스워드 비교 로직이다          |
| 공격 예시 | RSA 복호화에서 지수 연산 시간 차이를 분석하여 개인키 비트를 추정한다         |
| 전제 조건 | 공격자가 충분한 횟수로 시간 측정을 할 수 있어야 한다                   |
| 대응 방법 | 상수 시간 알고리즘 사용, 조건 분기 제거, 블라인딩 기법 적용이다            |
| 특징    | 암호 알고리즘 자체보다 구현 취약점을 공격한다                        |

## 2. 선택암호문공격 (CCA, Chosen Ciphertext Attack) – RSA

| 구분      | 내용                                                     |
| ------- | ------------------------------------------------------ |
| 개념      | 공격자가 임의의 암호문을 복호화 장치에 입력하고 그 결과를 이용해 원문이나 키를 추론하는 공격이다 |
| 공격 유형   | 적응적 선택암호문공격(CCA2)이 가장 강력한 공격 모델이다                      |
| RSA 취약점 | 기본 RSA는 곱셈 동형성을 가져 CCA에 취약하다                           |
| 대표 공격   | Bleichenbacher 공격 (PKCS#1 v1.5 패딩 기반)이다                |
| 공격 예시   | 복호화 성공/실패 여부만으로도 원문 정보를 점진적으로 알아낸다                     |
| 문제 원인   | 패딩 검증 오류 메시지 또는 처리 시간 차이다                              |
| 결과      | RSA 개인키 노출 또는 평문 복구가 가능하다                              |

## 3. OAEP (Optimal Asymmetric Encryption Padding)

| 구분    | 내용                                    |
| ----- | ------------------------------------- |
| 개념    | RSA를 선택암호문공격에 안전하게 만들기 위한 확률적 패딩 방식이다 |
| 전체 구조 | 평문 + 랜덤 시드를 해시와 XOR로 섞는 2단 마스킹 구조이다   |
| 보안 목적 | RSA의 결정성과 구조적 취약점을 제거한다               |
| 대응 공격 | 선택암호문공격(CCA)에 대한 안전성을 제공한다            |
| 핵심 특징 | 같은 평문이라도 매번 다른 암호문이 생성된다              |
| 사용 표준 | RSAES-OAEP (PKCS#1 v2.x)이다            |
| 보안 모델 | 랜덤 오라클 모델에서 CCA 안전성이 증명된다             |

## 4. 개념 간 관계 요약

| 항목      | 타이밍 공격       | 선택암호문공격      | OAEP          |
| ------- | ------------ | ------------ | ------------- |
| 공격/방어   | 공격 기법이다      | 공격 기법이다      | 방어 기법이다       |
| 대상      | 암호 구현이다      | 암호 시스템 구조이다  | RSA 암호화 방식이다  |
| 핵심 원인   | 시간 정보 누출이다   | 복호화 오라클 존재이다 | 랜덤 패딩 적용이다    |
| 해결 방식   | 구현 수준 대응이다   | 구조적 개선 필요이다  | 설계 단계에서 해결한다  |
| RSA와 관계 | RSA 구현을 공격한다 | 기본 RSA를 공격한다 | RSA를 안전하게 만든다 |

---

필요하면 **Bleichenbacher 공격 흐름**, **OAEP 내부 마스킹 단계**, **타이밍 공격과 사이드채널 공격 비교 표**까지 확장 정리해준다.
