
## 1. umask란 무엇인가

**umask(User File Creation Mask)**는
**파일이나 디렉터리를 생성할 때 기본 권한에서 “제거할 권한”을 지정하는 값**이다.

* 권한을 “부여”하는 개념이 아니다
* **기본 권한에서 빼는 마스크 값**이다

---

## 2. 왜 필요한가

* 모든 파일을 항상 같은 권한으로 만들면 보안 문제가 발생한다
* 사용자·서비스별로 **기본 보안 수준을 강제**하기 위해 사용한다

예시

* 모든 새 파일이 다른 사용자에게 쓰기 가능하면 위험하다
* umask로 기본적으로 쓰기 권한을 제거한다

---

## 3. 기본 권한과 umask 관계

리눅스/유닉스에서 생성 시 기본 권한은 다음과 같다.

| 대상   | 기본 권한           |
| ---- | --------------- |
| 파일   | 666 (rw-rw-rw-) |
| 디렉터리 | 777 (rwxrwxrwx) |

최종 권한 계산 방식

```
최종 권한 = 기본 권한 - umask
```

---

## 4. 계산 예시

### umask = 022 인 경우

#### 파일

```
666
-022
----
644  → rw-r--r--
```

#### 디렉터리

```
777
-022
----
755 → rwxr-xr-x
```

→ 소유자는 쓰기 가능, 그룹·기타는 쓰기 불가

---

## 5. umask 숫자의 의미

| 자리   | 의미          |
| ---- | ----------- |
| 첫 번째 | 특수 권한(보통 0) |
| 두 번째 | 소유자(user)   |
| 세 번째 | 그룹(group)   |
| 네 번째 | 기타(other)   |

권한 숫자 의미

* 4: 읽기(r)
* 2: 쓰기(w)
* 1: 실행(x)

예시

* umask 027

  * 그룹에서 쓰기 제거(2)
  * 기타에서 읽기+쓰기+실행 제거(7)

---

## 6. 자주 쓰이는 umask 값

| umask | 파일 권한 | 디렉터리 권한 | 사용 상황     |
| ----- | ----- | ------- | --------- |
| 022   | 644   | 755     | 일반 사용자 기본 |
| 027   | 640   | 750     | 서버/보안 강화  |
| 077   | 600   | 700     | 개인 비밀 데이터 |
| 002   | 664   | 775     | 협업 환경     |

---

## 7. 실무에서의 사용

### 현재 umask 확인

```
umask
```

### umask 설정

```
umask 022
```

### 영구 적용 위치

* 개인 사용자: `~/.bashrc`, `~/.profile`
* 시스템 전체: `/etc/profile`, `/etc/bashrc`

---

## 8. 실무 관점 핵심

* umask는 **보안 기본값 설정 도구**이다
* 서버에서는 너무 느슨한 umask는 위험하다
* 협업 서버에서는 그룹 쓰기 권한 고려가 필요하다
* 서비스 계정은 별도 umask 설정이 필수다

---

## 9. 한 줄 정리

> **umask는 새로 생성되는 파일과 디렉터리의 기본 권한에서 제거할 권한을 지정하는 보안 마스크이다.**
