# Java char 연산과 컴파일 오류 정리

## 질문

다음 코드 중 하나만 컴파일 오류가 발생하는 이유는 무엇인가.

```java
char b = 'a';
char a = b + 1;
char a = 'a' + 1;
```

---

## 결론 요약

컴파일 오류가 발생하는 코드는 `char a = b + 1;` 이다.

---

## 배경 개념

### char 타입

* `char`는 2바이트 유니코드 문자 타입이다.
* 내부적으로는 정수값(0~65535)을 가진다.

### Java의 산술 연산 규칙

* `byte`, `short`, `char`가 산술 연산에 참여하면 결과는 최소 `int`가 된다.
* 이는 Java 언어 명세에 의해 강제된다.

```text
char + int → int
char + char → int
```

---

## 코드별 상세 설명

### 1. `char b = 'a';`

* `'a'`는 `char` 리터럴이다.
* 문제 없이 컴파일된다.

---

### 2. `char a = b + 1;` (컴파일 오류)

* `b`는 변수이다.
* `b + 1`은 **런타임 산술 연산**이다.
* 산술 연산 결과 타입은 `int`이다.
* `int`를 `char`에 자동으로 대입할 수 없다.

따라서 컴파일 오류가 발생한다.

#### 해결 방법

```java
char a = (char)(b + 1);
```

---

### 3. `char a = 'a' + 1;` (컴파일 성공)

* `'a' + 1`은 **컴파일 타임 상수 표현식**이다.
* 컴파일러가 미리 계산한다.

```text
'a' → 97
97 + 1 → 98
```

* 결과값 98은 `char` 범위 내이다.
* 컴파일러가 이를 보장할 수 있으므로 암묵적 형변환을 허용한다.

---

## 핵심 개념 정리

### 컴파일 타임 상수 표현식

* 리터럴만으로 이루어진 식이다.
* 컴파일 시점에 값과 범위를 확정할 수 있다.
* 이 경우에 한해 `int → char` 자동 대입이 허용된다.

### 런타임 계산

* 변수가 포함된 식이다.
* 실행 시점까지 값이 확정되지 않는다.
* 자동 형변환이 허용되지 않는다.

---

## 정리 표

| 코드              | 컴파일 여부 | 이유           |
| --------------- | ------ | ------------ |
| `'a' + 1`       | 성공     | 컴파일 타임 상수    |
| `b + 1`         | 실패     | 런타임 계산 → int |
| `(char)(b + 1)` | 성공     | 명시적 형변환      |

---

## 한 줄 요약

Java에서는 `char`가 산술 연산에 참여하면 결과는 `int`가 되며, **컴파일 타임 상수인 경우에만 `char`로의 자동 대입이 허용된다**.

## 이유를 정확히 말하면

### 1, `int a = b + 1;`

* `b + 1`의 결과 타입은 `int`이다
* 좌변도 `int`이다
* **타입이 일치하므로 문제 없다**

---

### 2. `int a = 'a' + 1;`

* `'a' + 1`은 컴파일 타임 상수이지만
* 결과 타입 자체는 여전히 `int`이다
* `int`에 `int`를 대입하므로 문제 없다

---

## 핵심 정리

* **char 연산 결과는 무조건 int이다**
* `char`에 대입할 때만 형변환 문제가 발생한다
* `int`에 대입하면 컴파일 타임 / 런타임 모두 안전하다

---

## 한 줄 요약

`char`가 문제인 것이지 연산이 문제가 아니다.
**좌변을 `int`로 바꾸면 둘 다 정상 컴파일된다.**
