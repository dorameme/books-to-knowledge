| 구분              | 의미                                         | 사용 사례/용도                                    |
| --------------- | ------------------------------------------ | ------------------------------------------- |
| **프리이미지 저항성**   | 해시값만 알고 있을 때 원래 데이터를 찾는 것이 계산상 불가능함        | 비밀번호 저장: 저장된 해시로부터 원본 비밀번호를 알아내기 어렵게 함      |
| **제2프리이미지 저항성** (약한충돌내성)| 특정 데이터와 같은 해시를 갖는 다른 데이터를 찾는 것이 계산상 불가능함   | 디지털 서명: 서명된 문서와 같은 해시값을 가진 위조 문서를 만들기 어렵게 함 |
| **충돌저항성** (강한충돌내성)      | 서로 다른 두 데이터가 같은 해시값을 갖는 경우를 찾는 것이 계산상 불가능함 | 무결성 검증, 블록체인: 해시값 중복을 이용한 위변조 방지, 블록 연결 검증  |

1. 프리이미지 저항성: 공격자가 해시값만 알고 있을 때 원본 데이터를 찾는 것을 방지한다.
2. 제2프리이미지 저항성: 특정 데이터에 대해 동일한 해시값을 만드는 다른 입력을 찾는 공격 방지.
3. 충돌저항성: 해시함수 자체의 구조적 취약점을 이용한 충돌 발생을 막음.

순서상 강도: 충돌저항성 → 제2프리이미지 저항성 → 프리이미지 저항성. 충돌저항성이 가장 강력한 요구사항이다.
