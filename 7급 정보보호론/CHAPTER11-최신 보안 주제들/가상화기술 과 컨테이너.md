

## 1. 가상화 기술(Virtualization)

### 개념

**하나의 물리 서버에서 여러 개의 완전한 가상 컴퓨터를 실행하는 기술**이다.

* 각 VM은 독립된 OS를 가진다
* 하이퍼바이저가 하드웨어를 분할한다

### 구조

```
하드웨어
 └ 하이퍼바이저
    ├ VM1 (Guest OS)
    ├ VM2 (Guest OS)
```

### 특징

* OS 단위 격리
* 무겁고 자원 소모 큼
* 강한 보안 격리

### 실무 활용

* 클라우드 서버(AWS EC2)
* 서로 다른 OS 실행 필요
* 금융·레거시 시스템

---

## 2. 컨테이너 기술(Container)

### 개념

**OS는 공유하고, 애플리케이션 실행 환경만 분리하는 기술**이다.

* 커널을 공유한다
* 프로세스 단위 격리

### 구조

```
하드웨어
 └ Host OS
    └ Container Runtime
       ├ App + Lib
       ├ App + Lib
```

### 특징

* 매우 가볍다
* 실행 속도 빠름
* 배포·확장에 유리

### 실무 활용

* Docker, Kubernetes
* 마이크로서비스
* CI/CD 환경

---

## 3. 핵심 차이 표

| 구분       | 가상화(VM)  | 컨테이너 |
| -------- | -------- | ---- |
| OS 포함 여부 | 포함       | 미포함  |
| 커널       | 각자 보유    | 공유   |
| 실행 속도    | 느림       | 빠름   |
| 자원 사용    | 큼        | 작음   |
| 격리 수준    | 강함       | 상대적  |
| 배포 단위    | OS + App | App  |

---

## 4. 언제 무엇을 쓰는가

* **OS가 다르면** → 가상화
* **배포·확장이 중요하면** → 컨테이너
* **보안 격리가 최우선이면** → 가상화
* **대규모 서비스 운영이면** → 컨테이너

---

## 5. 비유로 정리

* 가상화
  → 집을 통째로 여러 채 짓는 것

* 컨테이너
  → 한 건물 안에 방만 나누는 것

---

## 6. 한 줄 정리

> 가상화는 OS까지 나눈 완전한 컴퓨터 분리이고,
> 컨테이너는 OS를 공유하는 가벼운 실행 환경 분리이다.
