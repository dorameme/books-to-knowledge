## 파밍
파밍(Pharming)은 사용자가 올바른 주소를 입력하더라도     
해커가 미리 조작해둔 가짜 사이트로 유도하여 개인정보를 탈취하는 아주 교묘한 수법.    


단순히 가짜 링크를 클릭하게 만드는 '피싱(Phishing)'보다 훨씬 위험한데,     
그 이유는 사용자가 주소창을 확인해도 정상 주소처럼 보이기 때문.

---

### 1. 파밍의 핵심 원리: "이정표를 조작하라"

인터넷은 주소(naver.com)를 입력하면 이를 실제 숫자로 된 IP 주소로 바꿔주는 DNS(Domain Name System)라는 이정표를 따라 움직여. 파밍은 바로 이 '이정표'를 조작하는 기술이야.

---

### 2. 작동 방식 (2가지 경로)

#### ① 사용자 PC의 `hosts` 파일 변조

 원리: 운영체제(Windows 등) 안에는 DNS 서버에 물어보기 전 가장 먼저 확인하는 `hosts`라는 텍스트 파일이 있어.
 공격: 악성코드를 통해 이 파일을 열어 `naver.com`의 목적지를 해커의 가짜 서버 IP로 바꿔버리는 거야.
 결과: 네가 주소창에 직접 `naver.com`을 쳐도, 컴퓨터는 `hosts` 파일을 보고 해커가 만든 가짜 네이버로 접속하게 돼.

#### ② DNS 서버 자체를 공격 (DNS Spoofing / Poisoning)

 원리: 인터넷 통신사 등이 운영하는 거대한 이정표인 DNS 서버의 데이터를 직접 조작하는 거야.
 공격: DNS 서버에 잘못된 IP 정보를 주입(Poisoning)해서, 해당 서버를 이용하는 불특정 다수의 사용자를 한꺼번에 가짜 사이트로 보내버려.
 결과: 내 컴퓨터가 깨끗해도 인터넷 서비스 자체가 오염되었기 때문에 피하기가 매우 힘들어.

---

### 3. 피싱(Phishing) vs 파밍(Pharming)

| 구분 | 피싱 (Phishing) | 파밍 (Pharming) |
| --- | --- | --- |
| 유도 방식 | 이메일, 문자 내 가짜 링크 클릭 유도 | 사용자가 정상 주소를 입력해도 유도 |
| 공격 지점 | 사용자의 심리 (속임수) | 시스템의 DNS 설정/파일 (기술적 조작) |
| 위험도 | 주소창 확인으로 예방 가능 | 주소창이 정상이라 알아채기 힘듦 |

---

### 4. 파밍 예방 수칙

 사이트 보안 확인: 금융 사이트 등에서 보안카드 번호 전체 입력을 요구하면 100% 파밍이야.       
 백신 업데이트: `hosts` 파일 변조를 막기 위해 실시간 감시를 켜둬야 해.         
 출처 불명 파일 금지: 파밍 악성코드는 보통 공짜 프로그램이나 메일 첨부파일로 들어와.
