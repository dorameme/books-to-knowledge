
##  1. 네트워크 진단 및 설정 (10개)

네트워크 연결 상태를 확인하고 장애 지점을 찾을 때 필수다.

1. **ipconfig /all (Win):** 모든 어댑터의 상세 정보(IP, MAC, DNS, DHCP)를 출력한다.
2. **ifconfig / ip addr (Linux):** 리눅스의 네트워크 인터페이스 설정 및 IP 주소를 확인한다.
3. **ping:** ICMP를 이용해 목적지와의 연결성 및 지연 시간을 측정한다.
4. **tracert (Win) / traceroute (Linux):** 목적지까지 도달하는 경로상의 라우터를 추적한다.
5. **netstat -an:** 열려 있는 모든 포트와 활성화된 네트워크 연결 상태를 확인한다.
6. **nslookup:** 도메인 네임과 IP 주소 간의 DNS 질의를 수행한다.
7. **arp -a:** IP와 대응되는 물리적 주소(MAC) 테이블을 조회한다.
8. **route print (Win) / route -n (Linux):** 현재 시스템의 라우팅 테이블을 확인한다.
9. **hostname:** 현재 시스템의 호스트 이름을 확인하거나 변경한다.
10. **ssh (Linux):** 원격 서버에 안전하게 접속하기 위한 보안 셸 프로토콜이다.

##  2. 파일 및 디렉터리 관리 (10개)

데이터를 생성, 이동, 삭제하는 가장 기본적인 조작이다.

11. **ls -al (Linux) / dir (Win):** 파일 및 디렉터리 목록을 상세히 출력한다.
12. **cd:** 작업 디렉터리를 변경한다.
13. **pwd (Linux):** 현재 작업 중인 디렉터리의 전체 경로를 보여준다.
14. **mkdir:** 새로운 디렉터리(폴더)를 생성한다.
15. **cp (Linux) / copy (Win):** 파일을 복사한다.
16. **mv (Linux) / move (Win):** 파일을 이동하거나 이름을 변경한다.
17. **rm -rf (Linux) / del (Win):** 파일이나 디렉터리를 삭제한다. (Linux의 -rf 옵션은 매우 강력하니 주의!)
18. **touch (Linux):** 빈 파일을 생성하거나 타임스탬프를 수정한다.
19. **cat (Linux) / type (Win):** 파일의 텍스트 내용을 한 번에 출력한다.
20. **chmod (Linux):** 파일의 권한(Read, Write, Execute)을 설정한다.

##  3. 시스템 관리 및 모니터링 (10개)

서버의 자원 상태를 파악하고 프로세스를 제어한다.

21. **top / htop (Linux):** CPU와 메모리 사용량을 실시간으로 모니터링한다.
22. **ps -ef (Linux) / tasklist (Win):** 현재 실행 중인 모든 프로세스를 확인한다.
23. **kill -9 (Linux) / taskkill /f (Win):** 특정 프로세스를 강제로 종료한다.
24. **df -h (Linux):** 디스크 공간 사용 현황을 사람이 읽기 편한 단위로 출력한다.
25. **du -sh (Linux):** 특정 파일이나 디렉터리의 용량을 확인한다.
26. **free -m (Linux):** 메모리(RAM) 및 스왑 영역의 여유 공간을 확인한다.
27. **uptime (Linux):** 시스템이 부팅된 후 가동된 시간을 확인한다.
28. **uname -a (Linux):** 시스템의 커널 버전 및 OS 정보를 확인한다.
29. **history (Linux):** 이전에 입력했던 명령어들의 목록을 보여준다.
30. **sudo (Linux):** 일반 사용자가 관리자(root) 권한으로 명령을 수행한다.

---

##  4. 텍스트 처리 및 고급 분석 (10개)

로그 분석 및 데이터 필터링에 특화된 명령어들이다.

31. **grep (Linux):** 파일 내에서 특정 문자열 패턴을 검색한다.
32. **find (Linux):** 이름, 크기, 권한 등 조건에 맞는 파일을 검색한다.
33. **tail -f (Linux):** 파일의 끝부분을 보여주며 실시간으로 추가되는 내용을 모니터링한다. (로그 분석용)
34. **head (Linux):** 파일의 시작 부분을 지정한 줄 수만큼 출력한다.
35. **more / less (Linux):** 화면 단위로 끊어서 파일 내용을 보여준다.
36. **vi / vim (Linux):** 텍스트 파일을 편집하는 가장 강력한 편집기다.
37. **diff (Linux) / fc (Win):** 두 파일 사이의 내용 차이점을 비교한다.
38. **echo:** 메시지를 출력하거나 텍스트를 파일에 저장(`>`)할 때 쓴다.
39. **tar (Linux):** 여러 파일을 하나로 묶거나 압축(gzip 등)을 해제한다.
40. **systemctl (Linux):** 시스템 서비스를 관리(시작, 중지, 상태 확인)한다.
